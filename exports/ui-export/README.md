# Echoes UI Baseline Export

基线整理时间：2026-03-30

这个导出包整理了 UI 重构前已经存在于仓库中的功能基线截图，并附带一个可直接打开的本地画廊页：

- `index.html`: 本地可浏览的重构前基线画廊
- `manifest.json`: 基线状态、截图与页面来源清单
- `screens/`: 导出的截图文件

建议使用方式：

1. 直接在浏览器打开 `index.html`
2. 或发送 `ui-export.zip` 给其他人做历史基线核对

说明：

- 本导出不是 Echo Listening System 的当前效果，也不能作为新版发布截图使用
- 本导出基于仓库中的既有截图资源整理，不是运行重构后应用重新采集
- 页面来源字段用于定位实现文件，便于从截图回溯到 Flutter 页面代码
- 新版 UI 导出将在 Android/iOS、明暗模式、三档布局和关键无障碍状态完成最终验收后重新采集；验收前缺失的画面不会使用概念图或伪造截图补齐
